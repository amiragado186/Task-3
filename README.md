Class 
1-  reference type

2-heap allocation
3-بنستخدمها مع الداتا ستراكشر المعقدة
object  نستعمله مدة طويلة وكتير

Struct
1-value type
بتخزن داتا حقيقية
2-stack allocation
وده يخلي ال instances الصغيرة والقصيرة اداءها احسن
3- افضل مع الداتا ستراكشر الصغيرة  

record
1-value type or reference
2-Heap by default
3-equality
بتختلف عن ال classes انها لو اتنين منها بيحملوا نفس القيم عادي يتساووا
4-Immutability
غير قابلة للتغيير وده بيخليها مثالية عندما لا نحتاج لتغيير الداتا
5-غالبا تستخدم في ارسال واستقبال ال DTOs
